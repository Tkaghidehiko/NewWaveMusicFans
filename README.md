# NewWaveMusicFans

最新の音楽情報を、海外の一次情報も踏まえて日本語でまとめる音楽メディア。
「AIによる高速な情報収集 × 運営者の編集方針でのブラッシュアップ」がコアの編集体制。

```
PCで編集 → git push → スマホ(claude.ai/code)で続き → git push → PCで pull
```
